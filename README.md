# tiny-chess-01

A chess engine in Python (standard library only), shipped as a single self-extracting `main.py`. It searches with principal-variation search, late-move reductions, a transposition table and quiescence search over a tapered PeSTO piece-square evaluation, under a fixed node cap per move.

Status: Standing v3 entry (PeSTO engine), dev Elo 1396; entries close 2026-11-25.
